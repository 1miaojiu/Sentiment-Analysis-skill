# 分析框架详解

本文档是五段式分析的方法论依据。执行分析时按此标准判断，避免过度解读和玄学化。

## 1. 情绪识别清单

按四类情绪族识别，先定族再定具体情绪，避免跳到结论：

| 情绪族 | 典型信号词/行为 | 常见误判 |
|--------|----------------|----------|
| 积极参与 | 主动提问、延续话题、用表情包、回复变长、分享日常 | 把礼貌性回复误判为好感 |
| 消极回避 | 回复变短、"嗯/哦/在忙"、话题终结者、延迟回复 | 把忙碌误判为冷淡（需结合历史回复基线） |
| 试探测试 | 反问句、"你是不是对谁都这样"、故意提其他异性 | 把缺乏安全感误判为玩弄手段 |
| 压抑不满 | 敷衍中带刺、突然客套、翻旧账、阴阳怪气 | 把直接抱怨误判为开玩笑 |

**判断基线原则**：判断情绪变化必须对照该联系人的历史回复基线（平均回复长度、速度、语气），而不是套用"通用标准"。基线数据不足时，降低置信度而非强行判断。

## 2. 需求识别清单（深层需求）

每条消息背后最多匹配 2 条需求，宁缺毋滥。常见需求按马斯洛简化为四层：

1. **安全感需求**：确认自己被重视、关系确定性、怕被敷衍。信号：反复确认行程、问"你有没有想我"、查岗式提问。
2. **被看见需求**：希望付出/情绪被注意到。信号：晒成果、说"没事"但语气低落、主动讲自己的难处。
3. **自主空间需求**：希望不被压迫、有自己的节奏。信号：拒绝过快推进、对安排表现出犹豫、"再看看吧"。
4. **乐趣陪伴需求**：要轻松愉快的互动，不想谈沉重话题。信号：发表情包、玩梗、主动起搞笑话题。

**匹配规则**：一条消息通常只对应 1 条主需求 + 至多 1 条次需求；同时判定 3 条以上 = 过度解读，必须砍到 2 条以内。

## 3. 回复建议三版本与评分标准

每处关键消息给出三版回复：

- **稳妥版**：安全、不出错，推进力度最小。适合关系温度 ≤4 或对方情绪为消极回避时优先给。
- **加分版**：针对识别出的主需求做精准回应，带轻微推进。适合温度 5-8 或积极参与时优先给。
- **暂不回复版**：说明什么情况下不回更好（如对方在气头上、话题已被终结、深夜情绪化时段），并给出重启话题的时机建议。

**评分标准（0-100）**，四个维度各 25 分：

| 维度 | 判分要点 |
|------|----------|
| 需求回应度 | 是否回应了识别出的主需求 |
| 真诚度 | 是否表达真实想法，而非套路化话术 |
| 压力适度 | 是否给对方留了回应空间（提问质量、不逼问） |
| 推进合理 | 推进力度是否匹配当前关系温度 |

## 4. 置信度规则

- **高（≥75%）**：有明确信号词 + 历史基线支持 + 上下文完整。
- **中（40-74%）**：信号存在但基线不足或上下文有缺口。
- **低（<40%）**：仅凭单条消息或推测链超过两跳。
- 铁律：推测链每多一跳（A → 说明 B → 意味着 C），置信度降一档。禁止输出无置信度标注的确定性情绪/需求结论。

## 5. 整体温度判断（1-10 分）

- 1-3：冷淡/疏远期——只给稳妥版，建议降低频率。
- 4-6：普通朋友期——稳妥版为主，加分版谨慎用。
- 7-8：暧昧升温期——加分版为主。
- 9-10：确定关系期——坦诚直接沟通优先。
