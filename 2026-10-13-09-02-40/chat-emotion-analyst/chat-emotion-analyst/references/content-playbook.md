# 自媒体内容规范（合规红线 + 内容模板）

本 skill 产出的任何对外内容必须经过本文档的合规检查。定位是「理解与真诚沟通」，不是「话术套路教学」。

## 1. 合规红线（不可违反）

1. **不做情感操控教学**：任何内容不得教授如何操纵、试探、控制他人情感。
2. **AIGC 标识**：AI 生成的图文/视频必须按《人工智能生成合成内容标识办法》添加「AI 生成」标识；发布时勾选平台的 AIGC 声明。
3. **隐私保护**：不发布可识别真实个人的聊天截图。一律使用重打文字版。
4. **平台适配**：抖音/小红书对"情感操控、PUA"类内容零容忍，被判定即限流封号。

## 2. 禁词/替词清单

| 禁用（操控感） | 替换为（理解感） |
|----------------|------------------|
| 拿下、套路、让她上头 | 理解、回应、看见她的需求 |
| 话术模板（照抄性质） | 沟通思路参考 |
| 测试她、推拉、欲擒故纵 | 确认感受、坦诚表达 |
| 攻心、拿捏 | 共情、换位思考 |
| 必杀技、绝杀回复 | 一个参考回法 |

## 3. 脱敏规范

发布任何案例前逐项检查：

1. 姓名替换为代称（"女生 A""小雨"等化名，避免真实昵称）。
2. 头像、微信号、手机号、转账金额、地点、学校/公司名全部移除或模糊化。
3. 时间改为相对时间（"上周三"），不保留精确日期时间。
4. 保留原文语气和句式，但允许删减无关片段、合并重复内容。
5. 文末固定声明：「案例经授权使用，细节已改编，人物为化名」。
6. 粉丝投稿：必须留存投稿人确认记录后才能使用；无法确认授权的素材一律不用。

## 4. 内容模板

### 4.1 小红书图文（主阵地）

```
标题（≤20字，给悬念不给结论）：
"她回'随便你'，我让 AI 分析了下，结果和我猜的完全不一样"

封面图：对话截图文字版（脱敏）+ 一个红色疑问

正文结构：
① 案例背景（2句：关系阶段 + 发生了什么）
② 对话原文（文字版，脱敏）
③ AI 拆解：表面意思 vs 潜在需求（用对比框呈现）
④ 三个回复版本 + 评分
⑤ 一句方法论总结（可截图传播的金句）
⑥ 互动引导："你收到过最难懂的回复是哪句？评论区投稿"

结尾固定要素：
- 「案例经授权使用，细节已改编」
- 「内容由 AI 辅助分析，已按平台规范标识」
```

### 4.2 公众号长文

```
标题：具体场景型，如《"哦"字回复背后的 4 种可能，AI 逐条分析给你看》

结构：
① 引子：一个脱敏案例（150字）
② 常规解读 vs AI 结构化解读的对比
③ 五段式分析全过程展示（教学价值核心）
④ 方法学说明：置信度、基线原则（建立专业信任）
⑤ 行动建议 do/don't 清单
⑥ 投稿入口
```

### 4.3 抖音口播脚本（后期再启用）

```
0-3s 钩子："女生说这句话，90% 的人第一反应都错了"
3-25s 案例呈现（文字版对话 + 旁白）
25-45s AI 拆解过程（录屏 skill 分析界面更有说服力）
45-60s 结论 + 互动引导
```

## 5. 发布节奏与选题库

- 周更 2-3 条，每次用 skill 批量产出 5-10 条存稿再发布。
- 选题优先级：有后续验证的案例 > 高频场景（已读不回、忽冷忽热、敷衍回复）> 方法论科普。
- 每条内容发布后记录数据（赞藏评、涨粉），数据好的选题方向加做系列。

## 6. 投稿回流流程（闭环关键）

1. 置顶评论/简介固定投稿指引："把你的聊天记录发给我，AI 帮你拆解"。
2. 收到投稿 → 确认授权 → 脱敏 → 分析 → 征求投稿人同意后发布。
3. 发布后追踪真实后续（对方实际怎么回应了），用于校准分析框架，形成"分析 → 现实验证 → 框架迭代"闭环。
